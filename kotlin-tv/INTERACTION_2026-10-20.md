# TV 交互优化（2026-10-20）

本轮针对定制原生版完成交互调整，包名 `com.hongguotv.custom`，保留版本 `0.9.0-custom` 和现有签名。本地调试 APK 已覆盖安装到小米 MiTV-AZFP0（Android 9 / API 28）；未发布到远端。

## 改动

- 首页“接着看”使用紧凑横卡，普通字号下首屏同时显示续播和六部热门剧；大字号下续播改为两列。海报仍保留完整比例。
- 搜索主动提交后聚焦第一条结果；等待过程中操作遥控器会取消自动抢焦点。空结果保留输入框，并展示当前类型最近五个搜索词。
- 输入框上下方向键可离开编辑区，光标位于末尾时向右进入搜索按钮；确认才弹出输入法，程序恢复焦点不再自动打开键盘。
- 选集焦点文字根据品牌底色选择黑或白，当前播放集附加圆点。播放侧栏与详情页都支持直接选择集数分组，分组切换后保留分组焦点，向下进入集数。
- 详情页与直接续播使用同一套按剧集 ID 匹配的续播规则。完成一集后明确显示下一集；已看完当前最后一集时进入详情，提供“重看最后一集”和“从第 1 集重看”。
- 播到最后一集显示“已追到最新”，由用户显式标记“整剧已看完”，不从现有集数推断内容已经完结。首页已完成记录不再错误承诺“接着看下一集”。
- 左右短按定位 10 秒；按住时按持续时间平滑增加偏移，显示目标时间及偏移量，松手才提交定位。边界限制在本集内，暂停状态保持不变；媒体专用快进键仍直接定位。
- 倍速直接放到播放器第一层控制区；清晰度、画面、定时等保留在播放设置。
- 选中剧卡显示确认操作和长按管理提示；导航改为“漫剧榜”，内容类型改为“漫剧 / 真人短剧”。
- 首页导航返回先提示“再按返回退出”，2.5 秒内再次返回才退出；其他按键或切后台清除退出计时。
- 故障恢复按当前播放档位提供更低档位，最低档不再提供无效降档；恢复降档仅用于本次观看及连播，退出播放器后恢复全局默认。主动修改全局清晰度会清除临时降档。
- 完整测试发现旧 APK 下载替换使用 `renameTo` 在 Windows 上无法覆盖已有文件，改为 `Files.move` 原子替换；保留校验后才替换的约束。

- `:app:lintDebug`：0 错误、26 警告；`:app:assembleDebug` 成功。

- 搜索实测：从搜索历史搜索“总裁”后聚焦第一条结果；提交后主动向右移动，结果加载完仍保留搜索按钮焦点。

- 故障降档策略已通过逻辑测试与代码检查；本轮未人为断开电视网络或制造硬件解码故障。长按不同遥控器硬件重复频率的完整实机矩阵、长期连续播放仍待验证。
